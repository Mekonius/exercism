This repository is a backup for my Exercism exercises and solutions.

[Exercism](https://exercism.org/) is a platform for learning programming through practice exercises and mentorship. This repository serves as a personal backup of my code and progress on the platform.

Each exercise is organized in its own directory, typically containing:
- Solution files
- Test files
- Exercise documentation
